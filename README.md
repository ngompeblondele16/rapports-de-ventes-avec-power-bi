# Rapports de ventes avec Power BI

Rapport interactif réalisé avec **Microsoft Power BI** pour suivre les ventes et analyser les commandes annulées.

## Contenu du rapport

Le fichier Power BI contient deux pages :

- **Suivi des ventes** : indicateurs de chiffre d'affaires, nombre de commandes, quantité vendue et commande moyenne. Des graphiques présentent l'évolution des ventes et leur répartition par région et catégorie de produits. Une table détaille les commandes.
- **Commandes annulées** : nombre et montant des commandes annulées, pourcentage d'annulation, évolution dans le temps, répartition par région et par catégorie de produits.

Les pages proposent des filtres interactifs, notamment par région et par période ; la page de suivi permet également de filtrer par statut de commande.

## Ouvrir le rapport

1. Installer [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Ouvrir le fichier `Mon Rapport Ventes.pbix` dans Power BI Desktop.
3. Si Power BI demande une connexion ou un chemin de données, configurer la source correspondante puis actualiser le rapport.
